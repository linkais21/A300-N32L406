NMEA 协议
背景

GNSS 接收机发出的 NMEA 语句符合 NMEA 0183 3.01/4.00/4.10 版协议标准。如需了解 NMEA
协议的更多内容，请访问 http://www.nmea.org/。

ALLYSTAR GNSS 接收机支持的语句

ALLYSTAR GNSS 接收机支持大多数 NMEA 通用语句，包括 GGA、GLL、GSA、GRS、GSV、RMC、
VTG、ZDA、GST、TXT。

NMEA 语句格式
ALLYSTAR  GNSS 接收机二进制协议规范        V2.3.6


NMEA 是 GNSS 的标准协议信息。ALLYSTAR GNSS 接收机支持以下 NMEA 语句：GGA、GSV、
GSA、RMC、VTG、ZDA、GLL、GRS、GST、TXT。该数据集包含 GNSS 接收机计算所得的完整的位置、速度、时间（PVT）信息。
每条语句都有一个前缀，以“$”开头，以回车符/换行符结束，为不超过 80 个字符的可见文本（含行终止符）。每条语句末尾都有一个校验和，读取数据的单元可能会对其进行检查。校验和字段由一个“*”和两个十六进制数字组成，代表“$”和“*”（不含这两个字符）之间所有字符的 8 位异或结果。有一些语句要求有校验和。
GRS、GSA、GSV 语句中不同的前缀表示不同的全球导航定位卫星系统：
$GP：GPS-QZSS-SBAS
$BD：BEIDOU
$GL：GLONASS
$GI：INSAT
$GA：GALILEO
$GN：GNSS，全球导航定位卫星系统组合定位。

有效载荷长度

有效载荷为一个 2 字节长的字段，它不包括除有效载荷（起始序列、信息 ID 等）之外的任何内容。这表示有效载荷长度的最小值可能是零。2 字节有效载荷长度与小端格式对齐。
有效载荷

有效载荷指信息内容。有效载荷内容及其详细信息会在后续章节说明。

结束序列

结束序列包括一个 16 位校验和。它的计算是 8 位 Fletcher 算法。校验和值是从信息 ID 的起始字节到有效载荷内容的最后一个字节计算的，计算校验和时忽略起始序列。
算法：
校验和 1 = 0
校验和 2 = 0
从信息 ID 至有效载荷的每个字节 B
校验和 1 = 校验和 1 + B
校验和 2 = 校验和 2 + 校验和 1
