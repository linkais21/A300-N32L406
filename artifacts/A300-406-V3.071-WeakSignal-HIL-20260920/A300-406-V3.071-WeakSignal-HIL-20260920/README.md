# V3.071 弱信号静止验证包

版本：T360-A300_406_20260920230201,V3.071。MCU：N32L406CBL7。
本包集成弱信号小速度误解锁保护、短暂丢星锚点保留及等价 Flash 优化。
App 105164 字节，Flash 剩余 1332 字节。

## 使用文件

- 已有 V3.070 设备优先用 `A300-406-OTA-V3071.bin`：保留参数，只更新 App。
  平台上传参数 deviceModel=A300-406、versionCode=3071，按既有平台流程生成分离签名。
  此 BIN 是 OTA 上传文件，不是包含分离签名的可直接下载响应；无需手动更改包头。
- 完整烧录使用 `SWD-Combined-V3071.hex`（自带地址）；对应 BIN 起始地址为 0x08000000。
  **合并包首次启动会执行工厂初始化，清除配置和 OTA 授权/升级状态。先备份设备参数。**
- 两种方式包含完全相同的 V3.071 App；不要把 SWD 合并 BIN 上传 OTA 平台。
  同一设备 SWD 到 V3.071 后通常不能再通过同版本 OTA 验证升级，请从现有 V3.070 选择 OTA。
- `diagnostics/` 为诊断与溯源文件；校验值见 `SHA256SUMS.txt`。

## 弱信号静止实机步骤

1. 升级后核对 App 显示 V3.071。从开始测试起保存完整 115200、8N1 串口日志和平台历史点。
2. 固定设备，先在能定位的环境保持静止至少 40 秒，确认 `[GPS-DRIFT] en=1 s=3 use=1`。
3. 保持设备和电源不动，通过遮挡 GNSS 天线环境制造弱信号，持续至少 10 分钟。
   记录 GNSS 有效性、HDOP、GPS-DRIFT 与平台 0200。原始 GPS 日志可能漂移，验收以
   滤波后的实际 0200 坐标和速度为准；GPS-DRIFT use=1 不是发送成功证明。
4. 已锁点、加速度平稳且卫星数<6或HDOP无效/>2.5时，原始1–3 km/h应保持
   上报速度0、经纬度固定。丢星期间仍应标未定位；10秒内恢复且无运动应沿用锚点。
5. 再做真实起步、0.5–3 km/h低速挪动、>3 km/h移动及定位恢复，确认坐标能正常更新。
6. 另测从上电开始就在弱信号区、以及失去定位超过10秒的场景，记录是否能重新锁点。

## 当前范围与未验证项

保护针对已经建立的静止锚点；初始持续假速度>1 km/h时仍可能无法进入锁点。
弱信号但HDOP/卫星数仍表现良好时，也可能走正常速度解锁路径；此包不能保证所有
多路径环境都零漂移。弱信号下极平稳的真实慢速移动可能延迟解锁，必须覆盖第5步。
