## 本次修复

有效行驶距离仍按原规则判定，再以毫米余数跨采样累计，满一米才更新原有整米里程。
修复原先每段丢弃不足一米距离造成的持续少计。静止锁定、低速防漂、异常跳点拒绝保持生效。
不按固定百分比放大，不补算历史丢失里程。含 V3.094 已有时间、日期和历史里程快照修复。

真实 C 回归：1000 段各 10.8 m，旧算法累计 10000 m，修复后累计 10800 m；
覆盖 0.6 m 增量、混合长度、重复采样、无效定位、静止/起步、跳点与低速拒绝及重启初始状态。
已接受余数在停车和暂时失去定位时保留；拒绝点不会获得余数。
余数仅在 RAM 中保存，重启最多丢弃此余数的 0.999 m；已有整米里程落盘机制不变。
突然失去全部供电或部分复位路径仍可能丢失尚未提交的整米里程，不承诺零回退。
JT808 里程仍为 0.1 km，内部持久里程仍为整米；外部 Flash 布局、配置格式不变。
