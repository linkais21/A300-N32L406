# 稳定性测试固件：SWD V3.040 → OTA V3.041

目标：A300-T9 / N32L406CBL7（128 KiB Flash、24 KiB SRAM）。生成于 2026-09-13。
仅用于用户要求的实机/HIL 测试。RAM/release-gate 未通过，不能视为正式发布版本。

## 直接使用的三个文件

| 文件 | 用途 | 参数 |
|---|---|---|
| SWD-Combined-V3040.bin | Bootloader + V3.040 App | SWD 烧录起始地址 **0x08000000** |
| SWD-Combined-V3040.hex | 同一镜像的 HEX 版本 | 文件自带地址，与 BIN 二选一 |
| OTA-A300-406-V3041.bin | 平台远程升级包 | 型号 **A300-406**；版本号 **3041**；显示 **V3.041** |

SWD Combined BIN 不可当作 App-only 烧录到 0x08006000，也不可上传为 OTA 包。
OTA 文件为 32 B A300 包头 + App；上传现有 FOTA 平台后使用平台分离式签名流程。

## 两个版本的差异

- V3.040：保留此前六项优化，新增 EC800M DMA 零计数/回卷接收边界修复；仍使用
  原 FOTA/AGNSS SHA 实现，先验证长时间挂测复位是否消失。
- V3.041：在 V3.040 修复基础上共用 App SHA-256 核心，保留所有 CRC/SHA/签名
  与 Flash 事务检查，用于第二阶段远程升级及运行验证。
- 两版使用相同的当前 Bootloader 和 FOTA-PLATFORM-P256 公钥；身份及配置格式不变。

## 测试顺序

1. 通过 SWD 写入 V3.040 Combined BIN 或 HEX 并回读校验。保留外部 SPI Flash 配置。
2. 串口 115200 / 8N1，确认启动版本 V3.040、主备鉴权和定位上报正常。
3. 保持与原挂测相同供电/天线/平台/上报周期，建议先连续运行 24 小时，记录
   Reset、RESET-DIAG、HEALTH、GPS DROP 和通信失败。不要刚上线就升级，以免混淆复位验证。
4. 第一阶段稳定后上传 OTA-A300-406-V3041.bin，选择 A300-406，版本号 3041，给测试设备
   创建升级任务；按现有开机检查流程触发。设备检查到的包长应为 **105192 B**。
5. 检查 accept version=3041、下载完成、签名授权、pending/reboot、新版 V3.041 启动。
   TRIAL App 约 30 秒后提交确认并主动复位一次属于现有流程，之后应稳定运行 V3.041。
6. OTA 后再次核对主备上线、定位上报、身份及配置保留，并继续挂测。

## 容量与未关闭项

| 版本 | App BIN | App 余量 | 静态 RAM | 已知调用链栈帧和 |
|---|---:|---:|---:|---:|
| V3.040 | 105800 B | 696 B | 17896 B | 2984 B |
| V3.041 | 105160 B | 1336 B | 17896 B | 2984 B |

两版扣除静态 RAM/已知调用链后仅余 3696 B，低于 4096 B 要求，且完整堆/异常/栈证据
未闭合。HEALTH 的 F=1 风险尚未关闭；不能通过调低阈值作为验收。
软件边界修复已通过 host 测试，但现场两次复位是否同源仍需要实机/HIL 验证。
本次没有烧录、上传、创建平台任务或发送设备控制。

## 校验与追溯

SHA256SUMS.txt 校验直接使用的文件。V3.040/、V3.041/ 保留 ELF/MAP、完整镜像、
容量/栈报告、带 release_approved=false 的哈希清单和构建来源。V3.040 使用归档的原
FOTA/AGNSS 源文件覆盖编译输入，不回滚工作树；provenance/rx-only.mk 记录此覆盖。
因 Makefile 提前展开前置依赖，V3.040 构建也产生未使用的 SHA 对象；最终 ELF 无共享
SHA 函数，已通过符号核对，其不属于实际可达固件代码。

构建和门禁命令及退出码：工作区 build/hil-stability-20260913/commands.json。
专用打包脚本：build/build_stability_pair_20260913.py，复用已有 HIL 包生成和校验函数。
正常发布入口未改，release-gate 失败状态保留。已有版本归档不覆盖。
