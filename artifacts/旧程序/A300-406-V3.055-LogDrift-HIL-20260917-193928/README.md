# A300-406 日志与静态漂移烧录测试包

版本：T360-A300_406_20260917193928,V3.055，OTA 计数保持 3055。目标为 N32L406CBL7 / 128 KiB Flash / 24 KiB SRAM。

## 烧录

1. 先保存设备参数。完整镜像包含 Bootloader、出厂初始化标记和 App，首次启动会重置设备配置和升级状态。
2. 推荐导入 `SWD-Combined-N32L406CBL7.hex`，HEX 自带地址；若用同名 BIN，起始地址必须是 **0x08000000**。不要将完整 BIN 写到 App 地址 0x08006000。
3. 烧录后执行校验、复位，重新配置服务器、APN、终端 ID 和设备 Key 等参数。调试串口 115200。设备完整版本查询/日志应显示上述版本。启动横幅使用 12 位编译时间，完整版本使用 14 位时间。

本轮包含 R 硬件 RTC 时间、4C 实际电压、6F SIM 会话状态与 ICCID 校验、当前创建时间、G452 静态漂移过滤移植。建议测试静置 35 秒后的漂移抑制、起步/振动释放、断网回放和休眠唤醒。

R 是硬件 RTC 当前值；本轮没有增加硬件 RTC 校时。静态过滤依赖有效 GNSS 和加速度样本，采样间隔超过 1 秒会清除锁定证据。

## 验证状态

App/Boot 构建、31 项定向回归、身份一致性、签名信任根、Boot RAM、Flash 容量和 HEX/BIN 往返验证通过。源码快照在 source，验证证据在 validation，所有文件校验值见 SHA256SUMS.txt。

**仅用于本次样机烧录测试，release_approved=false。** 完整发布门禁仍因全程序栈/堆/异常边界证据不足未通过。App Flash 剩余 648 字节；已知帧诊断下 SRAM 剩余 4096 字节，尚不能证明全部运行路径安全。需要实机/HIL 验证启动、日志、电压、漂移与 RAM 水位。

本包没有执行实际烧录，没有修改电脑产测工具或旧固件包。App 单独文件用于分析；本次请优先烧录上面的完整 HEX。
