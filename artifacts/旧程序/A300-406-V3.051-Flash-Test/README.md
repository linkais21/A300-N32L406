# V3.051 Flash 编译优化烧录测试包

目标：A300-406 / N32L406CBL7。硬件测试专用，**release_approved=false**。

## 烧录

- 推荐使用包根目录 **SWD-Combined-V3051.hex**，HEX 已含地址。
- 工具仅支持 BIN 时使用 **SWD-Combined-V3051.bin**，起始地址 **0x08000000**。两者选一个，用已验证的 N32L406CBL7 配置下载、校验并复位。
- **Combined 首次启动会清理配置 A/B、BCR、OTA 断点与授权记录。烧录前备份必要参数，首次成功启动后恢复配置。** 这是沿用的工厂初始化行为，不是此次新增功能。
- OTA-A300-406-V3051.bin 是同版本 App 的平台上传格式，需沿用平台签名/授权流程，不能当作原始 SWD BIN；本轮未上传平台。OTA 不更新 Bootloader。

本包沿用现有 V3.050 冷启动恢复逻辑，版本更新为当前已准备好的 V3.051，App 使用 -finline-limit=64。没有应用 ponytail 源码删改建议。完整 Flash 评估和审核见 FLASH-ASSESSMENT.md、PONYTAIL-AUDIT.md。

## 测试重点

1. 调试串口 USART1：115200、8N1、无流控，PA9 TX 接接收端，保存从上电前开始的完整日志。
2. 核对 `[BOOT] start=3051` 和 App **V3.051** 横幅；首次初始化后恢复测试参数。
3. 验证反复真实冷启动、联网/GNSS定位、主备上报、盲区补报、睡眠/唤醒、看门狗和受控 OTA 恢复；继电器相关测试沿用安全台架规程。
4. 记录复现步骤、时间、复位原因、日志和 RAM 水位。启动异常时保留供电和故障日志，不靠反复重启掩盖问题。

App 为 **104560 / 106496 字节，剩余 1936 字节**，仅比同源码原参数小 112 字节，Flash 余量仍不足 4 KiB 告警线。

构建、Flash/镜像/包校验已执行；正式 RAM 门禁因整程序栈证据不完整仍失败，详细证据保留在 validation 和 V3.051 中。**需要实机/HIL 验证**，不能把可烧录测试包视为已通过正式发布验收。

SHA256SUMS.txt 覆盖包内文件；V3.051 包含 ELF/MAP、版本清单与源码快照。审计中的源码路径相对于该快照的 provenance 目录。
