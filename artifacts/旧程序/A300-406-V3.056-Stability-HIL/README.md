# V3.056 稳定性实机测试包

仅用于专用测试设备。完整 release-gate 未通过：缺少全程序栈、堆峰值及中断嵌套上界证据。不能视为量产验收通过；需要实机/HIL 验证。

版本：T360-A300_406_20260917233517,V3.056，计数器 3056。
包含华大 TAU804M 在线 AGNSS、逐帧 ACK、OTA 检查请求的可选 IMEI 头及 Flash 优化。
App 106176 / 106496 字节，余 320 字节。静态 SRAM 18068 字节，已知主调用链 2408 字节，未扣未知栈/堆/IRQ 前余 4100 字节。

## 烧录

先保存服务器、APN、PID、设备 Key 等参数，敏感参数仅在本地保存。
推荐本次完整重测使用 Combined-N32L406CBL7.hex（自带地址）。
BIN 地址：Combined 或 Bootloader 为 0x08000000，App 为 0x08006000。
使用 SWD，选择 N32L406CBL7/128 KiB，烧录后执行校验，再复位。不要修改读保护/选项字节。

**重烧 Combined/Bootloader 后，原有出厂初始化逻辑会擦除外部 Flash 的配置、BCR、OTA 断点及授权记录。需重新配置设备。**
本包未修改 Bootloader 源码及升级安装/签名/回滚逻辑。只有 OTA 检查请求增加可选 X-Modem-IMEI 头。
不包含 OTA 平台上传包；这些 BIN 是 SWD 原始镜像。

## 测试记录

1. 调试串口 115200、8N1，全程保存日志；确认启动显示 V3.056，初始化成功，无连续复位。
2. 恢复设备参数，确认 4G 入网、JT808 注册/定位上报正常。
3. 保证 AGPS 开启（保留旧配置的设备需 AGPS=ON）。在无定位条件下检查华大下载、ACK 及 result 日志，比较定位时间；重复断网/恢复、GNSS 无信号/恢复。
4. 连续运行至少 24 小时，覆盖 ACC 开关、休眠唤醒、网络断开恢复；记录异常复位、卡死、停止上报及时间点。
5. 继电器验证仅在安全台架上执行。实际 OTA 下载/安装/回滚及与 AGNSS 争用需要单独实机验证；版本相同不会正常触发升级，不能关闭版本校验绕过。
6. IMEI 到平台管理页面的显示需要部署环境验证，Host 测试通过不代表线上已接收。

若出现卡死/复位，保留复位前后日志、供电及 ACC 状态、网络状态和发生时间。当前不能保证没有运行期栈风险。
