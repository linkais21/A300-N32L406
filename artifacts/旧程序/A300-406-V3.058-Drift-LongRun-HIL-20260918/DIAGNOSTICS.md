## 证据和边界

- 输入为用户提供的 COM12、2026-09-17 20:02:33 开始保存的日志，共 18794 行；其中 1503 条有效 GPS-INTEGRITY 定位速度均打印为 0.0。
- 日志 FOTA 检查显示版本号 3055；核对本地 V3.055 LogDrift 包的源文件，其 gps_report_filter.c 与本轮修改前工作树一致。日志没有镜像哈希，不能仅凭版本号证明烧录镜像身份。
- 原始 GPS-INTEGRITY 取 gps_get_data()，不是滤波后坐标。V3.055 实时 JT808 位置入口已调用 gps_report_filter_copy()。
- 当前算法需要 5 个、间隔至少 200 ms 的加速度样本窗口，最大单轴峰峰值不超过 30 mg，且速度不超过 1 km/h，连续满足 30 秒并有足够新 RMC 才锁点；达到 60 mg 或连续 3 个新 RMC 速度不低于 2 km/h 会解锁。
- Host 条件复现：速度保持 0，加速度 Z 在 1000/1040 LSB 交替，算法不能锁点。这是构造输入验证算法条件，不是对日志完整采样的回放。现有 ACCEL 日志属于另一个采样路径，无法重建滤波器的 200 ms 窗口。

## 新增日志

REALTIME 下沿用 GPS-INTEGRITY 的 30 秒节奏，追加：

```text
[GPS-DRIFT] en=1 s=2 use=0 b=80 span=20 t=4000
```

上例仅说明格式，不是实机结果。诊断读取不会增加传感器读取或改变锚点。

| 字段 | 含义 |
| --- | --- |
| en | 当前 STOPDRIFT 配置值 |
| s | 0 未知、1 移动/未满足静止条件、2 静止候选、3 已锁点 |
| use | 此诊断瞬间调用滤波复制，是否实际采用锚点；不是发送成功确认 |
| b | 自 init/reset 以来累计出现的阻断位，十六进制；不是当前故障，也不是发生次数 |
| span | 当前滤波窗口最大单轴峰峰值，单位 LSB；1024 LSB/g；证据清除后为 0 |
| t | 当前候选持续时间，毫秒；非候选状态为 0 |

| b 位 | 含义 |
| --- | --- |
| 01 | STOPDRIFT 或 GNSS 关闭 |
| 02 | 定位无效、过期、坐标/速度不合法等新鲜度校验失败 |
| 04 | 滤波加速度采样间隔超过 1000 ms |
| 08 | 加速度读取失败或样本不合法 |
| 10 | 新 RMC 时间与上一条间隔超过 3000 ms |
| 20 | 加速度窗口达到运动阈值 |
| 40 | 速度阻止候选或满足速度解锁条件 |
| 80 | 加速度窗口不满足静止阈值 |

唤醒、GNSS 开关等原有 reset 路径会清空累计位。多个位可以同时存在；早期失效位可能在恢复并锁点后仍存在。一次低频截图不足以判断阻断频率。
