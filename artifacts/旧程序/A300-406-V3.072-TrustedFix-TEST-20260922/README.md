# A300-406 V3.072 TrustedFix test package

用途：验证重启后无定位时，0x0200 是否使用外部 Flash 保存的最后可信经纬度。

- SWD/烧录整包：`Combined-N32L406CBL7.bin`，从 `0x08000000` 写入。
- 仅 App：`App-N32L406CBL7.bin`，从 `0x08006000` 写入；不要用 App 镜像覆盖 Bootloader。
- OTA：`A300-406-OTA-V3072.bin`，上传到 FOTA 平台，设备型号 `A300-406`，版本号 `3072`。
- `SHA256SUMS.json`：所有文件校验值。

建议验证：先在有定位环境运行至日志出现可信定位，再触发设备重启并立即制造无定位环境，检查启动后首个 0x0200 的经纬度是否等于重启前最后可信点；串口应出现 `[GPS] restored trusted fix ...`。

本包由当前工作树生成。发布 RAM/栈门禁未通过，需测试验证后再决定是否作为正式发布包。
