# A300-406 V3.060 参数修复烧录验证包

适用 N32L406CBL7 / A300-T9。版本：`T360-A300_406_20260918174645,V3.060`。
这是实机/HIL 验证包：`release_approved=false`，`hardware_verified=false`。未烧录设备。

## 烧录文件

- 合并 HEX：`SWD-Combined-V3060.hex`，自带地址，包含本次构建的 Bootloader 和 App。
- 合并 BIN：`SWD-Combined-V3060.bin`，起始地址 **0x08000000**。与合并 HEX 二选一，烧录后执行校验。
- **合并镜像首次启动会清除外部 Flash 的配置 A/B、BCR、OTA 断点和授权状态。烧录前记录设备参数；启动后恢复服务器、APN、设备身份及其他所需配置。** 盲区、AGNSS、Candidate/Factory/LKG 数据区不属于本次初始化清除范围。
- `App-V3060.bin` 地址 **0x08006000**，仅用于已有兼容 Bootloader 和设备状态的 App 单独更新。它不是完整空片烧录镜像。
- `Bootloader-V3060.*` 为配套引导程序；不要把 App 或 Bootloader 单文件当合并镜像使用。本包未包含 OTA 上传包。
- 调试串口 115200 / 8N1，核对 App V3.060、Boot 启动版本计数 3060。

## 改动

1. PID/FIP 文本命令先持久化、按原通道/设备标识/流水号反馈，再执行重连或重新注册；失败保存不执行配置副作用。
2. 标准 0x8103 APN 非空时关闭自动 APN，保存并反馈后重建 PDP；保留 AT 字符校验。
3. 车牌查询及启动日志采用 GBK；共享 39 项省份映射，兼容已存 UTF-8 与 GBK，持久化格式不变。
4. 精确命令 `APN,cmiot,,#`、`FREQ,10,60#` 已通过实际 C 主机链路回归；增加日志平台配置接收诊断。现场不能修改的现象尚未完整复现，不能据此宣称两项现场问题全部解决。
5. Flash 优化：共享车牌表/编码函数、共享配置数字解析和运行信息刷新，旧串口 SERVER/BSERVER/HEARTBEAT/TIMER 改用有界数字解析，拒绝空值、负数、尾随垃圾及 16 位溢出。合法参数范围和 TIMER 最小值钳制保留。默认内联阈值采用本次验证的 128，保留 main/FOTA 单次内联限制。

## 已验证与限制

- App、Bootloader 全量构建成功，无编译警告；release-guard、平台信任锚、Flash 检查、Boot 静态 RAM 检查通过。
- App **106380 / 106496 B**，Flash 剩余 **116 B**；容量已不过界，但余量很小，后续每次变更都必须重建检查。未扩大分区、删除安全校验或关闭日志，未采用实验中的加密实现/编译变体。
- 77 个相关测试脚本中，76 个最终通过。`test_at_config_handoff.py` 的主机 LTO 子项因当前 GCC 不支持 LTO 未完成；补充 O0/Os 串口并发交接测试通过。最初两个入口缺少新模块的链接失败已修复并重跑通过，原始失败日志保留。
- 完整 `release-gate` **未通过**：App 静态 RAM 17716 B，已知调用帧合计 2536 B，未计 heap/IRQ/未知路径前剩余 4324 B；缺失帧 73、间接转移 56、尾转移 131、环 1。不能认定整体栈/堆预算或设备长期稳定性已验证。Boot RAM 检查仅覆盖静态容量。
- HEX 校验和、地址、BIN 一致性、向量表、工厂初始化记录、合并偏移、版本和 SHA-256 已检查。

## 实机验收

1. 主/备平台分别下发 PID、FIP，确认结果能按原请求关联，随后重连和重新注册正常。
2. 下发 `APN,cmiot,,#`，以及平台标准 APN 参数修改；检查回读、PDP 重连、联网及断电后的参数保持。
3. 车牌设置粤字前缀，检查串口、CAR 查询、注册及平台界面；其他省份映射也应正常。
4. 日志平台下发 `FREQ,10,60#`，检查接受结果、回读、复位保持和移动/停车状态下的实际报文间隔；对照 20/120、30/180、60/300。
5. 验证定位、休眠/唤醒、看门狗、运行栈水位、网络故障恢复和长时间运行。

`validation/` 保存命令、退出码和门禁证据；`source/` 与 `source-hashes.json` 保存当前含既有未提交修改的构建输入；`MANIFEST.json` 为包内 SHA-256。未提交、推送、部署或烧录。
