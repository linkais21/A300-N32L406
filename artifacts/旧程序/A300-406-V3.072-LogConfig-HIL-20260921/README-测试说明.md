# V3.072 日志平台配置测试包

版本：T360-A300_406_20260921163125,V3.072。MCU：N32L406CBL7。

## 使用

- OTA：上传 `A300-406-OTA-V3072.bin`，deviceModel=A300-406，versionCode=3072；平台按现有流程生成分离签名。该文件不是 SWD 镜像。
- 烧录：使用 `SWD-Combined-V3072.hex`（自带地址），或 BIN 从 0x08000000 烧录。
- **完整合并烧录首次启动会执行工厂初始化，清除配置及 OTA 授权/升级状态；请先备份参数。** 已有设备优先用 OTA 保留参数。
- 两种方式使用相同 App。同一设备烧录 V3.072 后不要再用同版本 OTA 验证升级，应从低版本升级。

## 本次变化

取消日志平台每 60 秒查询；每次上电／重启联网后查询一轮，轮内最多 3 次尝试。保留 Pass/F39 设置链路、协议确认和日志上传。修复 JT808 广播函数两处残留的未声明 rc 判断。版本递增至 V3.072。

## 测试步骤

1. 升级后确认版本 V3.072，保存启动串口日志。
2. 启动前在日志平台放入字符串 Pass 配置，例如 HBT,120#；启动查询后确认参数及 0x14 回包。
3. 查询结束后再添加 HBT,180#，等待超过 60 秒应不再查询；重启后应取回并修改。
4. 覆盖无配置、服务器无响应、轮内重试，确保结束后不再周期重启查询。
5. 验证 JT808 0x8300、短信和串口设置仍正常；平台多参数使用一条 DUALSET 指令。
6. 断油电仅在安全台架验证，保持有效定位和低速限制；不要在行驶车辆上测试。
