# 原 V1.5.0 工具配套说明

实际使用的 EXE 是原文件 `生产测试工具/A300ProductionTester/bin/A300ProductionTester.exe`，未重新编译，SHA256：`C11CD59373BEC11C1B46CA29E6DDE9B0510AD66CADF717AD185BFEEBEC6FFC15`。

请运行同目录下新建的 `生产测试工具/A300ProductionTester/bin-test-A300-V3054/A300ProductionTester.exe`。它与原 EXE 完全相同，只复制了一份配置：

- `expected_version=V3.054`
- `terminal_model=T360-A300`
- TTS、RS485 均禁用
- orders、records 为空目录，不会触碰现场记录

不要直接运行原 `bin` 目录中的 EXE 做本次 V3.054 测试，因为原配置仍要求 V1.281/G452，会产生错误判定。首次联调前用新目录创建订单并填写现场实际参数。

V1.5.0 是旧的封闭 EXE，无法在无设备的情况下完成 GUI 实测；协议自动回放已验证固件响应格式，串口、GPIO、ADC、GNSS、继电器和真实 GUI 流程仍需要实机/HIL。
