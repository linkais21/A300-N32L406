## 本次变更及验证步骤

1. 位置参数下发 0029=30、0027=180、0020=0、0021=0，检查 0001 应答结果 0。
   通过 8106 查询四项，预期 30、180、0、0；重启后再次查询。
2. 0055 设置 100 km/h，查询/重启查询均应为 100。有效范围 20..200。
   受控测试超速持续 10 秒后报警；沿用既有 300 秒冷却策略。
3. 0020/0021 仅支持 0，其他模式应返回不支持且整包不应用。
   位置间隔沿用逻辑 ACC/工作模式、休眠定位开关和 GNSS 有效性条件。
4. 回归用户列出的全部十一项，检查查询与持久化；修改服务器参数放最后。
5. 验证上电、静止/行驶上报、睡眠唤醒、盲区补报及看门狗。
