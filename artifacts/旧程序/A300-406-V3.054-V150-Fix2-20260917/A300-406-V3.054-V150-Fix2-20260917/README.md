APN 参数仍经过长度/字符/持久化校验。APN 密码只在本地串口显式 APN 查询中按旧工具契约回读，SMS/JT808 回复不回显。
天线字段使用 UNKNOWN，不表示完成电气开短路检测。

## 烧录与重测

1. 使用 `SWD-Combined-N32L406CBL7.hex`（自带地址），或同名 BIN（起始地址 **0x08000000**）。这是 Bootloader + 出厂初始化标记 + App 完整镜像。
2. 出厂初始化会清除设备配置和升级状态；先保存要保留的参数。写后校验并复位，等待启动完成。
3. 继续运行 `bin-test-A300-V3054/A300ProductionTester.exe`（与原 bin 中 V1.5.0 字节相同），串口 115200、8N1。
4. 保留用户自己的 A300-406 订单、服务器、APN 和终端型号；预期版本 V3.054，TTS/RS485 不勾选，RTK 写入关闭。
5. 重新“写入并测试”。空 APN 凭据时应返回 `APN=Success!`，查询应为 `APN,CMIOT,,=Success!`；PARAM 应包含实际写入的 `MODEL[...]`。
6. 若仍失败，保存本轮测试明细及串口收发记录。不要跳过写入复检或人工改判成功。
