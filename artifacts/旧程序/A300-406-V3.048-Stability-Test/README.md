# V3.048 稳定性烧录测试包

目标：A300-406 / N32L406CBL7。版本计数 3048。
本包为 HIL 稳定性测试版，`release_approved=false`，未通过完整 RAM 发布门禁。

## 烧录

1. 先记录需要恢复的设备配置（主备平台、设备 Key 等保留在本地，不写进公开日志）。
2. 推荐选择 `SWD-Combined-V3048.hex`，HEX 自带地址。也可用 `SWD-Combined-V3048.bin`，起始地址必须是 **0x08000000**；二者二选一。
3. **Combined 首次启动执行工厂初始化，会清理设备配置 A/B、BCR、OTA 断点与授权记录。** 完成初始化后普通重启不再清理。恢复必要参数后测试。
4. 调试串口 115200、8N1，从上电前开始连续保存日志，电脑端启用时间戳。确认启动横幅为 V3.048，主/备通道按配置上线、GNSS 定位有效。

`OTA-A300-406-V3048.bin` 仅供现有平台的 App 升级，型号 A300-406、版本 3048，使用
平台现有分离式签名流程；不更新 Bootloader，不执行 Combined 工厂初始化。
不要把 Combined 或原始 App 当 OTA 包。目录内原始 App HEX/ELF/MAP 用于追溯，
本次稳定性测试按上述 Combined 流程建立一致基线。

## 这版包含什么

- 保留近期 DUP-01/02 共用、PERF-04 OTA 单次扫描、RAM-03 边界与 RAM-04 字段优化及串口统计。
- 修复配置查询异步缓冲提前释放、启动失败不释放、TX 引用过期栈内存，以及确认报文校验和。
- 没有修改硬件引脚、Flash 布局、GNSS 输出配置或里程防漂阈值。

49 个定向脚本和新增 UART 实际 C 测试通过；SHA 181 个摘要、真实平台签名、FOTA/Boot
回归、App/Boot 构建、镜像边界及 HEX/BIN 一致性检查通过。详细命令及结果在目录 validation
和 `REVIEW.md`。App 105184 B，Flash 剩余 1312 B；静态 RAM 17896 B。

完整 release gate 仍因全程序栈/堆/IRQ 证据不足拒绝。已知帧预算剩余 4160 B 不是实测
运行余量；历史 V3.047 的 RAM_GAP=3904/F=1 和 GNSS QDROP 尚未证明消除。
配置查询底层当前只发送 UDP，完整应答接收功能不在本轮实现范围。

## 建议稳定性测试

保持相同供电、天线、平台和上报周期，先静态连续挂测至少 24 小时。记录开始/结束时间、
人为重启、ACC 变化和参数修改，避免将这些动作误判为异常。

- 检查是否出现非人为重启、IWDG/HardFault、长期掉线或主备链路停止上报。
- 观察 HEALTH 的 STK_PEAK、RAM_GAP、HEAP_USED、F；F=1 仍视为余量告警。
- 记录 GPS QDROP 的起止值及每小时增量；CS/FMT/LDROP/OREF、定位有效性分别观察。
- 长稳基线完成后，再单独验证断网恢复、AGNSS/OTA 竞争、升级和掉电恢复，保留完整日志。

以上均需要实机/HIL 验证。本次生成文件未烧录、未上传平台、未发送设备命令。
