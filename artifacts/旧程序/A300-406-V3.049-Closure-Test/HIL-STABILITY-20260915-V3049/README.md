本轮 72 个定向 host 脚本退出 0；App/Boot 全量构建、镜像/包校验通过。App 104656/106496 B，余 1840 B；静态 RAM 17888 B。LOW_HEADROOM 仍存在，配置变化使历史基线不能直接用作优化收益对照。

完整 release gate 退出 2：全程序栈/堆/异常证据不足；已知调用帧和 2520 B，90 个缺失帧、57 个间接转移、115 个尾转移和 1 个调用环。已知帧预算通过不代表实际运行安全。实测要求 RAM_GAP≥4096 B、F=0；历史 QDROP/内存告警是否消除需本次日志证明。
