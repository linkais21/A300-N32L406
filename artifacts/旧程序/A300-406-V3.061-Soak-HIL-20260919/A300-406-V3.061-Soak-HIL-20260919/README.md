## 挂机建议

先确认冷启动、联网、定位和主副平台上报，再至少连续运行 24 小时，条件允许可延长至 48–72 小时。
保留完整串口日志及开始/结束时间，记录每次异常复位、看门狗、掉线恢复、ACC/休眠唤醒和 HEALTH 栈水位；同时观察报文间隔、定位漂移、参数保持与平台在线状态。
在受控测试阶段覆盖一次断网恢复、一次断电重启及 ACC 唤醒；OTA 使用单独升级阶段记录，避免与基线挂机结果混在一起。
挂机通过标准是无非预期重启/卡死、网络故障后可恢复、参数保持和上报节奏符合配置。水位日志不能单独证明最坏栈上限。
