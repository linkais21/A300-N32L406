## 本次修复与测试步骤

上报速度、经纬度锁定与里程使用同一静止判定。静止锁定后，原始 GNSS 坐标漂移不再累计里程；确认移动后的第一个有效定位点重新建立里程基准，不补算停车漂移。

1. 升级后核对版本为 V3.092，确认止漂功能启用。
2. 设备保持静止、ACC 常开，不休眠；确认定位有效，等待现有约 30 秒静止锁定形成。
3. 持续观察至少两小时：平台速度为 0，经纬度固定，里程始终保持开始值。包含弱信号和小速度噪声场景。
4. 检查设备内部米级里程及 JT808 0x01 里程，避免仅看平台 0.1 km 显示而遗漏小幅增长。
5. 开始真实移动：确认锁定正常解除、位置更新、里程重新累计，且没有补算停车漂移。
6. 核验 ACC 开关、短时定位丢失、重新定位、断电重启和配置保持。将结果填入 HIL-测试记录.md。

现有静止锁定仍要求新鲜 GNSS 质量、低速度及稳定加速度；禁用止漂或证据失效时不能保证锁定。实际 GPIO、传感器、GNSS、Bootloader 跳转和 OTA 安装效果需要实机/HIL 验证。
