# V3.088 连续未定位上报时间修复测试包

完整版本：`T360-A300_406_20261007171447,V3.088`；MCU：N32L406CBL7；OTA 型号：`A300-406`；版本号：`3088`。

上一版修了唤醒首包，但后续周期包在未定位时仍使用旧采集时间。本次统一全部新 work-mode 未定位 0200 为推进的事件 UTC，保留可信旧坐标、逻辑 ACC，清除 GPS 当前定位位。不等待搜星完成才报告唤醒事件。
0201 查询保留定位采集 UTC；同一盲区事件的存储重试保留原时间/ACC/内容。有效 GNSS 恢复后使用真实测量 UTC，保留 GNSS/NTP 双向校时。
全部新未定位报告输出 `[808-EVENT]`：ts 为实际 0200 本地 BCD 时间，acc/fix 来自实际状态位；tx=0 仅代表主通道提交成功，不代表主平台 ACK 或显示。
震动 6 秒确认、ACC 防抖、GPIO、ISR 和 Flash 布局沿用上一版。

普通 OTA 测试使用版本低于 3088 的设备（如 V3.087）；不要先烧新 App 再期待同版本升级。

## 实际功能复测场景

| 场景 | 验收观察 |
|---|---|
| 主平台在线、GNSS 未定位，硬件 ACC 唤醒 | 连续首、二、三、四包 ACC ON、fix=0，时间按配置周期推进；核对串口 ts 与平台原始包 |
| 物理 ACC OFF、主平台在线、GNSS 未定位，震动确认唤醒 | 同样核对连续四包，逻辑 ACC ON；首包及时发送，记录震动起止及状态转换时刻 |
| 之后 GNSS 恢复有效定位 | 定位位恢复，使用真实测量时间，轨迹继续生成；另核对 GNSS/NTP 校时 |
| 静止休眠后再次唤醒 | 状态位切换正常，新未定位报告时间继续推进 |
| 未定位时位置查询 | 0201 保留采集时间，区分查询响应与新的 0200 |
| 无网络时唤醒并上报，恢复网络后补报 | 历史事件保留原时间/ACC；新在线报告使用新事件时间 |
| 正常 OTA；下载断网/断电后恢复 | 续传、校验、安装、重启与版本确认正常，配置及连接恢复 |

V3.087 日志确认两种唤醒首包 ACC=1、fix=0 且传输提交成功，之后继续发送；后续包时间由用户主平台观察确认，旧日志未打印对应载荷时间。脱敏排查报告见 diagnostics/连续上报时间排查与复测说明.md。
以上均为 V3.088 待执行的实际验收场景，本包未烧录、未上传；连续包时间、主平台接收和长期稳定性需要实机/HIL 验证。
