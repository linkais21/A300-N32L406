# V3.087 ACC / 震动唤醒首包时间修复测试包

完整版本：`T360-A300_406_20261007163524,V3.087`；MCU：N32L406CBL7；OTA 型号：`A300-406`；版本号：`3087`。

本次修复 ACC / 震动唤醒首包使用旧定位采集时间的问题。无有效定位时，状态切换首包使用当前事件时间、可信旧坐标和逻辑 ACC；GPS 定位有效位仍清零。
普通无定位报告和 0201 查询继续保持原采集时间。已存盲区事件的时间和 ACC 不因重试改变。
保留 V3.086 的震动确认修复、原 6 秒确认条件和 ACC 防抖；未修改 GPIO、传感器寄存器、协议格式或中断策略。
首包不等待 GNSS 搜星；如果平台过滤未定位包，需要结合主平台原始收包核对。
增加 `[808-EVENT]`：t=发送尝试结束的 MCU 毫秒计数，acc/fix=实际 0200 位，ts=实际本地 BCD 时间 YYMMDDhhmmss，tx=广播传输结果。
tx=0 表示主通道提交成功，并不代表平台业务 ACK/显示。无坐标或设备标识日志字段。
新版本尚未烧录，硬件及主平台接收效果需要实机/HIL 验证。

## 实际功能复测场景

下表均为新版本待执行的实机验收场景，本包生成不代表实机通过。
记录人工震动起止时刻、带时间戳的串口日志与平台原始收包时间，避免把整段休眠时长当作唤醒耗时。

| 场景 | 验收观察 |
|---|---|
| ACC 物理 OFF，设备静止进入休眠，平台在线后持续有效震动 | 采样满足确认条件后 SLEEP->REALTIME、logical_acc=1；记录实际耗时，不能仅凭机械震动恰好 6 秒判断 |
| 连续震动中存在短波谷 | 小于 1 秒的波谷且总体命中率达标时，保留 V3.086 确认修复，窗口不被短波谷反复清零 |
| 单次敲击、稀疏震动、超过 1 秒中断 | 不误确认；长间断后重新计时 |
| 无 GNSS 有效定位时震动确认，网络与平台在线 | 确认后先收到 0200，bit0=1（ACC ON）、bit1=0（未定位），时间为当前事件；核对 808-EVENT 和主平台原始收包，不能只看地图页 |
| 之后 GNSS 恢复有效定位 | 随后收到有效定位包，轨迹继续生成，避免重复模式首包 |
| 无网络时震动确认，恢复网络后 | 核对盲区存储和补报、重新上线与 ACK；首包不能承诺在断网期间平台即时收到 |
| ACC 电平唤醒及再次静止休眠 | ACC 唤醒正常，休眠恢复正常；休眠 0200 时间继续推进 |
| 正常 OTA 与下载中断网/断电后恢复 | 续传/校验/安装/重启确认成功，版本为上述完整版本；配置与平台连接恢复 |
