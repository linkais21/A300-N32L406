# V3.085 休眠定位时间修复验证包

完整版本：`T360-A300_406_20261005002819,V3.085`  
OTA 版本号：`3085`；设备型号：`A300-406`；MCU：`N32L406CBL7`。

本包修复休眠周期 0200 时间固定在最后一次定位时刻的问题。
休眠包沿用最后可信坐标，时间按已运行的 SysTick / STOP1 RTC 推进，
保持“未实时定位”标志。默认停驻上报间隔统一为 300 秒。
已保存的参数不会被强制覆盖，已有 8103/FREQ 设置仍优先。
普通无定位包及 0201 查询仍保留坐标采集时间。

## OTA 验证步骤

1. 使用已有兼容 Bootloader、当前版本低于 3085 的测试设备。
2. 上传 `A300-406-OTA-V3085.bin`，型号 `A300-406`，版本 `V3.085`，版本号 `3085`。
3. 为本次测试设备创建升级任务，保留正常的型号、版本和签名校验。
4. 等待下载、校验、安装、重启确认和成功上报；核对设备报告完整版本为上述 V3.085。
5. 核对 JT808 恢复在线、心跳正常及配置仍保存。成功安装后不应再次提供同版本普通升级。

## 休眠上报验收

1. 发 `FREQ,30,300#`，确认参数应答；进入休眠后持续采集至少两个周期的原始 JT808 包。
2. 检查休眠包仍为 0200，ACC OFF，未实时定位；坐标可保持不变，但时间应按约 300 秒推进。
   例如 `19:34:03 → 19:39:03 → 19:44:03`，不能一直停在休眠入口时间。
3. 下发 8103 的 `0x0027=60`，确认成功应答，并检查后续休眠包按约 60 秒推进。
4. 再发 `FREQ,30,300#`，确认恢复 300 秒间隔；验证心跳仍正常。
5. 验证 ACC/连续震动唤醒、重新取得实时定位以及恢复后的运动上报。
6. 平台若不更新展示，先核对原始包中的 BCD 时间是否已推进，区分设备与平台处理。
