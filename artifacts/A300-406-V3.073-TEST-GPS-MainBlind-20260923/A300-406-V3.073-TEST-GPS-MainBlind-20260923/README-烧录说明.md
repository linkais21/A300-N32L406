# A300-406 GPS与主平台盲区修正测试包（非正式发布）

仅适用于 N32L406CBL7 / A300_406。不是 N32G452 固件。
内部版本字符串仍为 V3.073；请用本目录 TEST 包名及 SHA256 区分，不能凭 V3.073 判断已更新。

## 烧录现有设备

优先选择本包 App-*.hex（文件自带地址）；使用 App-*.bin 时起始地址必须填写 **0x08006000**。
这是 App-only 测试包，要求设备已有匹配的 Bootloader。只擦写 App 涉及的扇区，不执行整片擦除，不从0x08000000写入BIN。
不要烧录工厂初始化包，不清除外部 Flash，以保留设备参数和历史记录。烧录后校验并复位运行。
不含 Bootloader、Combined 或 OTA 包；未上传平台、未发布、未代用户烧录。

## 本包变化

- 保留此前GPS逐星载噪比修正，配套生产工具V1.6.2。
- 主平台断开或发送失败时存储盲区，副平台继续实时发送。
- 主平台恢复鉴权后向主平台补报，收到匹配成功ACK才消费；副平台不能发送或消费主平台盲区。
- 副平台断开不影响主平台，不为副平台单独存储。
- IP/FIP端点配置只重连对应的一路；共享PDP重启除外。

## 建议验证

1. 设置ACC ON上报间隔10秒，读取确认生效，保持ACC ON及定位正常。
2. 两平台在线后，只使主平台不可达并保持至少1分钟；确认副平台仍在线上报、设备出现盲区存储日志。
3. 恢复主平台，确认主平台收到0x0704历史补报并回复成功ACK；副平台保持实时上报。
4. 只使副平台不可达，确认主平台继续每10秒上报，不产生副平台专属盲区积压。
5. 再验证主副同时断开、重启保留记录及恢复补报。请保留完整串口和主平台日志。
