# A300_406 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a stable N32L406CBL7/BY25Q16ES firmware that preserves required A300 behavior, retains only Huada and Zhongkewei AGNSS, and performs authenticated, recoverable OTA without bricking.

**Architecture:** Keep the existing single-loop A300 application, but place all external-Flash users behind one serialized storage service. Add a small non-upgradable bootloader that validates and installs signed application images from BY25Q16ES using redundant BCR/LKG/Factory state. AGNSS is split into explicit TAU804M/Huada and ATGM332D-F7N/Zhongkewei adapters selected by product configuration.

**Tech Stack:** C99, ARM GCC Cortex-M4 hard-float, N32L40x SDK 2.2.0, BY25Q16ES SPI NOR, host-side Python protocol tests, SWD hardware-in-the-loop tests.

## Global Constraints

- Target MCU is N32L406CBL7 at 64 MHz with 128 KB internal Flash and 24 KB SRAM.
- Internal Flash: bootloader `0x08000000-0x08002FFF`; application `0x08003000-0x0801FFFF`; release app <=110 KB.
- External Flash layout: Candidate `0x010000`, Factory `0x080000`, LKG `0x0C0000`, Resume/BCR `0x100000`, blind-zone `0x110000`, AGNSS slots from `0x1B1000` onward.
- Version string is exactly `T360-A300_406_20260823000000,V3.000` in all release-controlled outputs.
- Only TAU804M/Huada and ATGM332D-F7N/Zhongkewei AGNSS are shipped; C21/BK and all other AGNSS paths are removed.
- OTA has priority over AGNSS, blind-zone, and configuration writes; no dynamic allocation or unbounded wait is permitted.
- Preserve unrelated user changes already present in the working tree; each task must list only its intended files in commits.

## File Map

- `include/ext_flash_layout.h`: single source of truth for BY25Q16ES addresses, sizes, magic values, and slot headers.
- `src/spi_flash.c`, `include/spi_flash.h`: bounded SPI NOR transactions, status polling, page/sector operations, readback, and arbitration hooks.
- `bootloader/`: standalone startup, linker script, BCR state machine, image verifier, installer, and recovery loop.
- `src/fota.c`, `include/fota.h`: Candidate download, HTTP Range resume, package validation, and bootloader handoff.
- `src/agnss_manager.c`, `include/agnss_manager.h`: scheduling, mutual exclusion, retry deadlines, and receiver selection.
- `src/agnss_huada.c`, `src/agnss_zhongkewei.c`: vendor-specific protocols using a shared stream interface.
- `src/agnss_storage.c`, `include/agnss_storage.h`: dual-slot external-Flash AGNSS cache.
- `src/gps.c`, `include/gps.h`: explicit TAU804M/ATGM332D-F7N selection and binary-safe UART injection; no C21 detection.
- `src/jt808.c`, `src/at_config.c`, `src/geofence.c`, `src/peripherals.c`, `src/rtk.c` and corresponding headers/Makefile entries: approved feature trimming.
- `src/power_mgr.c`, `include/power_mgr.h`, `src/hw_init.c`: STOP2 entry/exit, clock restoration, and safe fallback.
- `tools/tests/`: host tests for parsers, storage headers, BCR transitions, and package validation.
- `docs/superpowers/specs/2026-08-27-a300-406-migration-design.md`: approved design; update only when requirements change.

## Execution order and checkpoints

Tasks 1-4 establish the storage and OTA safety foundation. Task 5 must be complete before either vendor AGNSS adapter is integrated. Task 7 can proceed after Task 2 but must finish before final size measurements. Task 8 depends on the final resource ownership rules from Tasks 2, 4, and 5. Tasks 9-10 are release gates and cannot be skipped or replaced by a successful compile alone.
