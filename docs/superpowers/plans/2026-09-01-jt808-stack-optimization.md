# JT808 栈占用优化实施计划

1. 增加 host 回归，先证明注册响应当前会在 RX 回调内保存并发送（RED），再约束延迟认证、重复包和链路失效行为。
2. 将 RX 数组缩减为 CH0/CH3 两槽，并在槽内原地反转义。
3. 引入每链路待认证事务，由 `jt808_process()` 在链路同步后保存和发送。
4. 引入带 busy 所有权的静态组帧/转义工作区，替换关键发送路径的大局部对象。
5. 将配置候选副本移到受保护的静态工作区，保留失败不提交语义。
6. 添加并接入基于 `-fstack-usage -fno-lto` 的关键函数栈门禁。
7. 运行定向测试、相关回归、应用/bootloader 构建、release/RAM/stack guards 和差异检查；生成新的 HEX 哈希。
8. 交付 HIL 步骤；不在本轮自动烧录设备。
