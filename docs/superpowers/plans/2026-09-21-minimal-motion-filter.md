# 最小静止/移动判别实施计划

用户授权先复核 Flash，再落地三个最小改进；不补传候选轨迹、不修改发布包。

1. 固定 V3.071 当前输入，独立构建基线，保留修改前文件。App 分区不扩大，
   必须通过 Flash 硬容量检查；完整 RAM 门禁原有不足如实报告。
2. 回归先行：低质量不得新锁点、30秒候选期间不集中不得锁点、弱信号平稳低速
   需要有界确认、跳点/折返/速度不支持的漂移不能触发确认、丢星/传感器故障/
   时间回绕/重置必须正确撤销证据。
3. 最小过滤实现：新锁点需 fix_quality>0、卫星>=6、0<HDOP<=2.5；延用原30秒、
   <=1km/h和加速度条件。候选期以第一点为参考，所有新点需在8米半径内，
   保留首点及最近4点求截尾均值。不使用可能陈旧的休眠位置强制约束新锚点。
4. 已锁点时对>=0.5km/h的低速加入疑似状态；不替代既有明显速度/加速度释放。
   最长60秒，至少10秒，累计位移>=4米、方向持续且与航向相符，位移/速度积分
   比在0.5..2之间才确认。跳点、明显折返、速度/航向失效、数据间断取消疑似。
   未确认时继续使用锚点；超时撤销证据，不直接放行。已锁点短丢星10秒策略保留。
5. 仅确认移动事件通知JT808：在线且当前定位有效时下一次调度立即尝试当前0200。
   失败最多每秒重试，事件15秒过期；复用在线首点发送器，不产生或消费盲区事务、
   不改历史时间。任一在线通道发送成功即确认事件，与既有实时发送成功语义一致。
6. 真实C和实际编码测试，独立ARM构建、release-guard、RAM诊断、范围差异复核。
   超容量先精简本次实现，不删功能或放宽门禁。无用户要求不重新发包或烧录。

局部距离仅用于分类，原始/报文坐标仍保留double。经度差处理日期变更线，
纬度投影使用余纬正弦七阶多项式，绝对截断误差小于0.000161，
覆盖赤道/中纬度/高纬度边界。不依赖新libm三角库。
GNSS位移/速度/航向并非独立真值；相互一致的多路径漂移仍可能误解锁。
需要实机/HIL对照静止误解锁次数与0.5–3km/h移动解锁延迟/距离。
