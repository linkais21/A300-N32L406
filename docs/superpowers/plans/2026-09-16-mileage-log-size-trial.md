# 里程数学与日志体积试验

目标：测量两个独立候选对 ARM 最终 BIN 的净收益及兼容性，不更改默认固件、发布版本或已交付包。用户已授权源码级试验；不烧录、不部署、不提交。

1. 记录当前参与构建的源码、Makefile 和工具链身份。输出到新的 build 子目录，拒绝覆盖已有试验。
2. 从当前生产源码生成隔离候选：数学只替换 mileage.c 的距离函数，保留 double 经纬度及相减，采用标准库 float 三角函数；日志只裁剪显式列出的逐包/逐点正常路径跟踪调用。默认生产源码不写入试验开关。
3. 编译真实 mileage.c 的 host 回放入口，比较当前 double 实现和候选的距离、过滤、整米累加、基准推进、重复调用及持久化行为。覆盖小位移、全球随机点、极区、跨日期线、0.5/1000 米及整米/防漂边界。局部距离误差 <= 1 cm 是试验筛选线，不是用户已批准的新产品精度；报告所有决策差异，禁止以误差通过代替行为等价。
4. 日志只更换白名单调用，不删除控制流、失败日志、OTA、身份、命令回复、产线判定、恢复日志或计时保护。保留参数求值并证明正常状态下仅丢弃指定文本；记录白名单和原始调用以便审核。
5. 运行基线、仅数学、仅日志、组合四组全量 ARM 构建，检查 BIN/MAP、ELF/HEX 大小、静态 RAM、栈证据及数学符号；运行当前门禁并保留已知失败。修改候选后只重跑受影响组。
6. 按 requesting-code-review 做范围内自审，写出收益、误差分布、兼容性差异及采用建议。不能证明边界等价的数学候选仅作为 opt-in 试验保留，不自动替代默认实现。需要实机/HIL 验证运行时序、里程累计与日志对接。

交付：可重复试验脚本、数学候选片段、host 回放/契约测试、尺寸与误差 JSON、报告和隔离 ELF/HEX/BIN。没有额外发布打包步骤。
