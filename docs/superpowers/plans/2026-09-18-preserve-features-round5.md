# 第五轮：间接转移和 AT 防重入证据

承接第四轮，原工作树本地执行，保留所有既有改动。固件功能、版本、日志、编译参数和交付产物不变。

1. 保存源码/构建输入身份和分析器快照；核对最终 ELF 的 modem、F39、micro-ecc 回调与跳表。
2. 已发现分析器遗漏 TBB/TBH。先用反汇编夹具复现错误的 complete=true，再将跳表纳入全局和入口可达未知项；不得把表内目标默认为函数内部或已证明。
3. 用真实 ec800m.c 的 host harness 验证 AT owner 拒绝、URC 延迟、单次出队、防重入、失败/超时、过期代数和恢复。用临时源码突变验证关键断言敏感性，不改固件源码。
4. 固定版本头在独立 build/optimization-round5-20260918/final 构建；执行相关 host tests、完整 release-gate 及差异检查。保存命令、退出码、输入哈希和二进制对比。
5. 报告回调候选与机器码证据边界，明确尚未证明的 RAM 条件，判断第六轮是否必要。

验收：跳表不能被静默遗漏；关键 AT 保护条件有可执行拒绝路径证据；未知回调目标、库帧、尾转移、调用环和异常栈仍失败关闭。此轮不承诺全程序栈证明或 Flash 节省。硬件、中断嵌套及运行栈水位需要实机/HIL 验证。
