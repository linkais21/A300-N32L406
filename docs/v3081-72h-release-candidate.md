## OTA 断电与断网验收

本轮 OTA 验收采用正常远程升级流程，不包含人为制造回滚或使用 SWD 覆盖 App。中断后允许从有效检查点续传，也允许重新从零下载；必须最终完成升级，不能停留在不可启动状态或反复重启。

1. 正常结果：设备下载并校验平台授权包，进入 `pending`、`trial-ready`，启动 V3.081；试运行确认后上报 `success ack=1 clear=1`，下一次检查不再提示该版本更新。
2. 下载阶段断电：重启后旧版仍能运行，并可重新检查、下载直至完成。安装阶段断电：恢复供电后 Bootloader 继续完成安装，最终启动 V3.081。
3. 下载阶段断网：仅在专用设备和隔离测试环境中短暂中断下载连接；恢复后观察重试或重新检查、继续下载、安装及成功回执。安装开始后不依赖网络继续写入，联网恢复后仍需完成确认和回执。
4. 每个中断点检查串口日志：Bootloader 有界推进或 App 正常启动，无持续重启、HardFault、看门狗循环、无法联网或无法再次升级。保留完整串口日志和平台任务结果；报告中脱敏设备标识、地址和令牌。
