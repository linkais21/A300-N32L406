# 第十轮：共用默认配置与会话发送记账（2026-09-19）

本轮在 V3.065 当前未提交工作树上完成保持功能的 Flash 优化，净省 **1024 B（1 KiB）**，App 余量由 **40 B 增至 1064 B**。达到 1–2 KiB 目标下限，未达到 4 KiB 告警阈值。完整发布门禁仍失败，不能作为已验证发布包。

## 实际修改

- `src/flash_config.c`：7 处默认配置赋值共用 `config_defaults()`，以 `noinline` 防止编译器在各路径重复生成稀疏初始化。完整默认结构赋值保持一致；原来的锁、槽选择、代际比较、旧格式迁移、失败恢复及持久化顺序不变。单项实测节省 944 B。
- `src/jt808.c`：注册和鉴权发送后的记账共用 `note_session_send()`。保留成功、明确失败和结果不确定三种处理、原请求流水号、重试/退避、日志格式与参数，以及迟到 ACK 的匹配。帧申请和头部构建失败仍在原调用点消耗重试预算。叠加后再省 80 B。
- `tools/tests/test_jt808_registration_tx.py`：更新结构断言，检查两个调用点传入各自操作，且共用实现仍保留发送记账与不确定结果判断。真实 C 会话行为由既有双平台回归覆盖。
- 本文、[执行计划](superpowers/plans/2026-09-19-preserve-features-round10.md)及 `build/optimization-round10-20260919/` 中的独立构建/快照/验证证据。

未修改功能开关、版本身份、编译参数、分区、协议、默认值、Flash 格式、Bootloader、交付包或门禁阈值。未删日志、校验、超时或恢复路径。用户已有其他修改保留；本轮未提交、推送、部署或烧录。
