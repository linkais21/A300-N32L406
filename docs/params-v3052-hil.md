# V3.052：0x8103 与数学/日志瘦身烧录验证包

目标 N32L406CBL7 / A300-406。硬件验证专用，`release_approved=false`。

## 烧录

推荐 `SWD-Combined-V3052.hex`（含地址）。若使用 BIN，选择
`SWD-Combined-V3052.bin`，起始地址 **0x08000000**。只选其中一个。
**Combined 首次启动会沿用工厂初始化流程，清除配置 A/B、BCR、OTA 断点及授权记录；先备份设备参数，首次启动后恢复。**
OTA-A300-406-V3052.bin 是平台上传格式，不可当原始 SWD BIN；沿用平台签名/授权流程。
本轮未烧录、上传、部署或启动服务。

USART1：115200 / 8N1。应看到 App **V3.052** 与 Boot 3052。
包中的 SHA256SUMS.txt、MANIFEST.json、ELF/MAP、编译源码及验证日志用于核对。
不要使用同目录名称不带 `-Final` 的早期打包草稿；它未完成身份复核。

## 参数契约

以工作区 808 部标 2013 协议原文为准，数值均为大端。

| ID | 类型、单位 | 本机接受范围及生效位置 |
|---|---|---|
| 0001 | DWORD 秒 | 1..3600，心跳及低功耗时间表 |
| 0013 | STRING | 1..63 字节 IP/域名，字母数字点连字符，不含端口 |
| 0018 | DWORD | 1..65535，共用 TCP 端口，同时更新主备端口 |
| 0027 | DWORD 秒 | 5..18000，静止/休眠上报间隔；保留既有是否休眠定位的模式开关 |
| 0029 | DWORD 秒 | 5..18000，缺省/行驶上报间隔 |
| 0080 | DWORD 0.1km | 0..42949672，乘 100 保存为米，拒绝溢出 |
| 0081 | WORD | 省域 ID，保存并用于下次 0100 |
| 0082 | WORD | 市县域 ID，保存并用于下次 0100 |
| 0083 | STRING GBK | 1..15 字节，拒绝 NUL/控制字符/残缺双字节，保存并用于 0100 |
| 0084 | BYTE | 0/1/2/3/4/9，颜色，0 为未上牌 |

保留 0010/11/12 APN、0017 备地址、0040 电话的配置存储与查询。
APN 继续沿用原配置语义，本次不新增即时 PDP 重启。
原先错误占用的 0014 备地址、0020/0023 上报间隔不再作为别名接受。
0x8104 空消息查询全部；0x8106 指定查询；0104 内容含应答流水号、数量和大端参数。
旧 UTF-8 车牌仍通过已有转换发送 GBK；本次 0083 下发按 GBK 原字节存储。
F39 文本读取该车牌时客户端需注意编码，不声明统一 UTF-8 文本表示。

完整消息先校验再一次双槽事务保存：错误长度/截断/尾随数据/重复 ID/范围错误不部分应用。
未知设置项整包回复 3（不支持）；格式/值错误回复 2；工作区或存储失败回复 1；成功回复 0。
相同配置重发不重复写 Flash。服务器变化清除对应授权，先在原通道尝试应答，再由主循环重连；
车辆信息变化清除主备授权并在后续流程重新注册。应答发送失败不撤销已经持久化的配置。
省市颜色使用原 reserved 的六字节，保持结构大小、旧字段偏移及 CFG_VERSION=4；旧零配置沿用默认颜色 1。

## 大小与验证

| 方案 | ELF/B | HEX/B | App BIN/B | App 剩余/B |
|---|---:|---:|---:|---:|
| 旧默认 V3.051 | 161208 | 294158 | 104560 | 1936 |
| 数学+日志+毫米量化实验 | 151004 | 275033 | 97756 | 8740 |
| 本包（再加入 0x8103） | 151112 | 276436 | 98256 | 8240 |

比旧默认少 6304 B；比毫米量化实验增加 500 B。ELF/HEX 大小不是实际 Flash 占用。
App 分区仍为 106496 B；保留 Cortex-M4、hard-float、-Os、LTO、独立段与 gc-sections。
数学/日志优化继续通过实验生成器的显式源码覆盖构建，本包 `compiled-overlays` 是实际编译输入。
普通 `make all` 仍使用原数学/日志源码，不能拿它代替本包重现命令。

量化使用最近整数毫米，再按 >500 且 <1000000 毫米累加，每段截断为米；
不是与旧阈值完全等价，之前 6 条约 69..71km 合成轨迹里程差为 0/0/0/+1/+2/+1 米。
保留错误、启动、身份、OTA 和 modem 日志，仅裁剪四条普通追踪日志。

自动验证覆盖：真实参数 C 单测与 CH0/CH3 帧收发/读回/注册、配置 NOR 掉电与迁移、
F39、主备会话、里程持久化、毫米边界、工作区所有权、身份和镜像格式。详见 validation。
版本常量测试最初因仍期待 V3.051 失败，同步到 V3.052 后重跑通过。
编译、Flash、release-guard、平台信任锚、libc 与必要栈帧检查通过。
**完整 release-gate 仍失败：整程序栈/堆/异常上界证据不完整。**
static RAM=17884 B，已知调用帧=2536 B，未知堆/IRQ前剩余4156 B，
仅比4096 B必要间隔多60 B，不能据此证明 RAM 安全。

## 实机测试清单

1. 冷启动及版本核对、恢复测试服务器和参数。
2. 下发十项（换服务器放最后或单独测试），检查原通道 0001 成功与 8106 读回；错误报文应失败且原值不变。
3. 0080=12345 读回12345，对应1234500米，0200里程附加项为12345；行车后继续累加。
4. GBK 车牌、省市、颜色修改后抓下一次0100；重启后读回不变。
5. 0013/0018 修改后原通道先应答、新端点连接并注册；主备分别验证，OTA占用时验证延迟重连。
6. 心跳、行驶/静止周期、静止漂移、GPS重复点、里程边界和重启持久化。
7. 冷启动、盲区补报、睡眠唤醒、RAM水位和看门狗，必要时掉电恢复。

以上硬件项均**需要实机/HIL 验证**。8240 B不是未来 AGNSS/产测进一步对接后的承诺余量。
